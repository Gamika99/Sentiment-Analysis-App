ℹ️ About This Project

This sentiment analyzer uses a Logistic Regression model trained on 50,000 IMDB movie reviews. The text is preprocessed with stemming, stopword removal, and converted to numerical features using TF-IDF vectorization. The model achieves ~92% accuracy on held-out test data.

🔬 Model: Logistic Regression + TF-IDF (5000 features)
📊 Dataset: IMDB 50k (balanced: 25k positive, 25k negative)
🚀 Response time: <200ms per prediction

Made with ❤️ using Python, Flask, Scikit-learn • Sentiment Analysis Web App
